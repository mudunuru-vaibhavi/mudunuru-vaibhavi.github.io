# Vaibhavi Mudunuru · Portfolio

Personal portfolio: health data analyst and clinical data engineer. Static HTML and CSS, no build step, hosted on
GitHub Pages at [mudunuru-vaibhavi.github.io](https://mudunuru-vaibhavi.github.io/).

| Path | What it is |
|---|---|
| `index.html` | Home: projects, how I work, experience, skills, contact |
| `projects/clarity-agentic-etl/` | Case study: self-healing Epic Clarity ETL |
| `projects/hedis-outreach-rag/` | Case study: HEDIS gap-closure outreach |
| `projects/data-tokenization/` | Side project: Data Tokenization (PHI-safe geocoding) |
| `projects/rosetta-omop/` | Case study: Rosetta: OMOP multi-site ETL and RWE study |
| `assets/style.css` | One stylesheet for every page (light and dark themes) |
| `assets/img/` | Dashboard screenshots from each project |
